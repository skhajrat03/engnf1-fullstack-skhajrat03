# AI Usage Documentation

## 1. Overview

During the development of **TriageSync – Resource Booking and Management System**, I used AI tools as development assistants to improve my understanding, troubleshoot technical issues, and make the development process more efficient.

AI was used as a support tool, while I was responsible for understanding the implementation, integrating the features, testing the application, and making development decisions.

## 2. AI Tools Used

- **ChatGPT (OpenAI):** Used for technical guidance, debugging assistance, code suggestions, understanding concepts, and documentation support.

## 3. Areas Where AI Was Used

AI assistance was used in the following areas:

### Frontend Development
- Understanding React.js components and component structure.
- Troubleshooting frontend errors.
- Improving UI implementation and CSS styling.
- Understanding React Router and protected routes.
- Integrating frontend components with backend APIs.

### Backend Development
- Understanding Express.js routes and controllers.
- Debugging API errors and incorrect imports.
- Implementing and understanding middleware.
- Understanding JWT authentication and role-based authorization.
- Improving error handling and API response structures.

### Database Management
- Understanding MongoDB and Mongoose.
- Debugging database connection issues.
- Understanding database schemas and relationships.
- Working with user, resource, and booking data.

### Feature Development
AI assistance was used to understand and troubleshoot the implementation of features such as:

- User authentication and authorization.
- Admin authorization middleware.
- Resource management.
- Booking creation and cancellation.
- Booking approval and rejection.
- User management and account activation/deactivation.
- Admin dashboard statistics.
- User search and role filtering.

### Debugging and Deployment
- Understanding error messages and troubleshooting solutions.
- Resolving frontend and backend integration issues.
- Debugging MongoDB Atlas connectivity.
- Understanding deployment configuration and environment variables.

### Documentation
- Improving project descriptions.
- Preparing technical documentation.
- Understanding project architecture.
- Writing clearer explanations of implemented features.

## 4. How AI Assistance Was Used

AI tools were primarily used to:

1. Explain unfamiliar technical concepts.
2. Suggest possible solutions to programming errors.
3. Provide implementation guidance for specific features.
4. Review code structure and identify potential issues.
5. Help understand API integration and authentication workflows.
6. Improve technical documentation.

AI-generated suggestions were reviewed and adapted before being incorporated into the project.

## 5. My Contribution and Responsibility

I was responsible for:

- Understanding the project requirements.
- Designing and developing the application.
- Implementing and integrating frontend and backend functionality.
- Configuring the database and application environment.
- Testing features and troubleshooting issues.
- Reviewing and validating AI-assisted suggestions.
- Managing the source code using Git and GitHub.
- Deploying and maintaining the application.

I take responsibility for the final implementation and functionality of the project.

## 6. Verification and Testing

AI-assisted suggestions were not treated as automatically correct. I reviewed the suggested solutions, integrated relevant changes, and tested the application to verify that the implemented functionality worked as expected.

## 7. Transparency Statement

AI tools were used as supplementary learning and development resources, not as a replacement for my own understanding and implementation work.

The purpose of using AI was to learn unfamiliar concepts, solve technical problems, improve development efficiency, and build a better understanding of full-stack application development.
